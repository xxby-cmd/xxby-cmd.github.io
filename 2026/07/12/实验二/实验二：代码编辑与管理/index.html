实验二：代码编辑与管理

姓名：贾国龙 　　学号：22070809

一、实验目的

1.安装Visual Studio Code（VS Code）文本代码编辑器；

2.安装和配置Markdown相关插件，掌握代码编辑器插件的基本概念；

3.学习Markdown基础语法，使用VS Code完成Markdown文档的编辑和渲染。

二、实验环境

项目 内容
操作系统 Windows 11 专业版 25H2
网络 互联网
文本编辑器 VS Code 1.127.0
VS Code插件 Markdown All in One、Markdown Preview Enhanced、Paste image等

三、实验过程

3.1 首先安装VS Code

这里我前期就已经安装好，验证内容如下

3.2 扩展安装

点击左侧第五个扩展按钮，依次安装Markdown All in one，Markdown Preview Enhanced，Paste Image，MarkdownLint四个插件，其余插件可以自行扩展安装。

3.3 配置基础设置优化体验

3.3.1. 开启自动保存：按 Ctrl + , 打开设置，搜索 files.autoSave ，设置为 afterDelay

3.3.2. 开启单词折行：搜索 editor.wordWrap ，设置为 on

3.3.3. 配置图片粘贴路径：设置 Paste Image: Path Type 为relative

3.4 创建并编辑第一个Markdown文件

3.4.1 创建并保存文件

按下 $Ctrl+N$ 键创建一个新文件，然后按下 $Ctrl+S$ 键将其另存为一个新文件


3.4.2 编辑文件

按照基础语法内容，比如 “#” 代表一级标题，以及如何插入表格等规则，实现一篇Markdown文档的编写，值得注意的是，本篇报告就是本人第一次用Markdown写的，还怪好用的。

五、知识总结

名称 内容 体会 注意点
VS Code 作为一款轻量级的文本编辑软件，配合各种插件能够实现快速地文本编辑 写文档时一些格式都已经定义好，这大大提升了写作效率 各种语法内容仍需要不断记忆和编写，因为还有各种各样的数学公式等
Markdown 该插件实现了VS Code作为编辑器使用通用格式编辑内容的需求 Markdown种的模板、实时预览、组件、转换等功能特别好用 仍需不断熟悉使用相关组件和模板
编写文件 自行编辑Markdown文件时，具备很高的自由性，且不需要像Word一样时时刻刻注意格式内容 大大提高编写文件的效率 配合模板使用事半功倍

六、出现问题

  • 编写文档时，很多情况下都会遇到不知道怎么版的时候，比如怎么插入表格，怎么缩进，甚至怎么插入空格，这时候就需要自行去查找相关知识进行学习。

七、心得体会

7.1 技术层面

本次实验中，我理解并掌握了VS Code的安装以及相关插件的安装使用，还有一些Markdown的排版知识和内容。

7.2 思政层面

本次实验加深了我对于写作的指导，写作论文使用Markdown、Latex的好处就在这里，很多时候数学公式以及模板的定义对于论文写作来说是非常重要的。
