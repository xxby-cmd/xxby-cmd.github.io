实验一：Web环境配置与静态节点构建

1. 实验目的

本次实验旨在自行安装好web环境后，自行开发并运行一个web博客，了解和掌握web开发环境的配置，理解web软件的B/S框架架构特点以及静态节点和动态节点的区别。

2. 实验环境:

内容 版本
操作系统 Windows 11 专业版 25H2
运行环境 Node.js 24.18.0
包管理器 npm 11.16.0
代码管理 Git 2.55.0.windows.2
构建工具及本地服务器 Hexo-CLI 4.3.2
文本编辑器 VS Code 1.127.0

3.1首先安装Node.js以及npm、Git、Hexo-CLI等相关环

3.1.2 安装git并选择VS Code作为默认编辑器，并设置全局用户名和邮箱
3.1.3安装Hexo-CLI并验证是否安装成功

5. 知识总结

名称 内容 意义 注意事项
下载文件 国外的网站下载速度一般都很慢，因此要尽可能使用国内的镜像软件下载 大大提高工作效率 找到正确的、安全的镜像网站
静态节点 指将本地的代码文件转化为网站上的可视化图形 兼顾对外展示和对内维护 构建、维护的代码仍需要不断加强学习
命令提示符 命令提示符不仅用于打开本地文件，也可用于从网上下载资源。 将图形化页面转为最原始的代码页面，提高程序员思维能力 各个命令要不断加以总结和记忆
Hexo-CLI 作为博客网站部署的地基，配置好初始化的博客项目，以及执行相关命令和提供本地预览服务 提高程序员搭建网站的效率 要知其然更要知其所以然，要理解hexo的背后工作逻辑
Git代码管理和版本控制 Git的速度极快、且只是对比差异项座位版本区别，具有高效率、小体积等优点 给大型项目以更多的容错率 注意git的使用项目和说明手册

6. 出现问题

本次实验中，我主要出现了以下问题，并提供了相应的解决方案：

  • 环境配置问题，面对国外网站打不开、下载慢的问题，我采用了国内镜像网站作为替代。
  • 代码编辑问题，有许多代码书写规范，我翻了很多错误，然后我查阅相关资料并自学后一一改正。

7. 心得体会

本次实验中，我跟着实验手册完成了一个最简单博客网站的搭建，但是如同雾里看花始终不清楚内在逻辑，因此下一步我将搞明白这一本地博客、web环境的底层逻辑。
