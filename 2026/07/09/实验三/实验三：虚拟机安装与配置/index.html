实验三：虚拟机的安装与使用

姓名：贾国龙 　　学号：22070809

一、实验目的

  1. 使用虚拟机工具（VirtualBox）安装Linux系统（Ubuntu Server）；

  2. 通过克隆技术构建一个多机虚拟化环境；

  3. 了解和掌握基于虚拟机的开发环境的基本构建方法和配置。

二、实验环境

项目 内容
操作系统 Windows 11 专业版 25H2
网络 互联网
硬件 CPU支持VT-x/AMD-V虚拟化技术；内存≥8GB；硬盘剩余空间≥50GB
软件 Oracle VirtualBox

三、实验过程

3.1 安装软件

3.1.1 首先安装Oracle VirtualBox

访问VirtualBox官网，并下载Windows版本的安装包进行安装，然后重启电脑。

3.1.2 下载Ubuntu Server 26.04 LTS ISO镜像

访问Ubuntu官网下载 26.04 LTS版本。

3.2 创建虚拟机

打开VirtualBox软件，点击新建，然后输入虚拟机名称，选择虚拟机系统镜像为上面下载的linux系统，分配内存资源和硬盘资源，再点击创建虚拟机。

然后不运行虚拟机，在设置–网络里面打开网卡2，勾选启用网络连接，配置为仅主机模式，实现双网卡。

3.3 启动虚拟机，安装Ubuntu Server

启动虚拟机，在出现的页面中选择 “Try or Install Ubuntu Server”，然后跟随指引选择相应选项，

注意：

1.存储配置选择 “Use an entire disk”

2.设置用户名和密码务必按空格键选中“Install OpenSSH server”

等待安装完成后重启

3.4 配置静态IP地址

启动虚拟机运行，然后输入用户名和密码

注意密码的输入是不回显的，输入正确后回车即可

3.6 克隆虚拟机

  1. 关闭模板机： sudo shutdown now
  2. 在VirtualBox中右键点击模板机 → “复制”，选择 “完全克隆”
  3. 重复三次，分别克隆出 node1 、 node2 、 node3

3.7 修改克隆机的主机名和IP

对每台克隆机，都重复上述过程，分别将其主机名改为node1/node2/node3，将ymal文件中的静态ip改为102/103/104

3.8 验证多机环境

在node1上测试多机互连，当能正常出现收包时间时即成功连通。

五、知识总结

名称 内容 体会 注意点
虚拟机 关于VirtualBox的安装以及镜像的安装，然后配置虚拟机的相关设置包括网卡、名称等 配置时往往具有多个功能，需要自己思考寻找 不要乱配置，因为可能稍微一动就会出错
linux操作系统 关于linux操作系统的文件更改，ip配置，以及相关命令的使用 和传统图形化界面有很大区别，都是考指令和代码完成操作 仍需不断熟悉相关命令
多机互连 实现多台主机连通，形成一个局域网 这也许就是网络初具雏形时的局域网，也就是网络的雏形，可以思考类比互联网 配置ip地址，已经验证成功时需要不断尝试

六、出现问题

  • 修改ymal配置文件时，需要严格控制缩进，只要锁紧不一样就会出现问题。
  • linux系统可以用上下键调出之前的命令，但是也会出现的是之前修改的内容，因此要想查看最新的配置情况需要自己重新写入命令。
  • ping主机时，可能会产生ip重叠的情况，这时候只需要再重启一下虚拟机即可。

七、心得体会

7.1 技术层面

7.2 思政层面

本次实验加深了我纯代码页面的理解，减少了图形化界面的依赖程度，这对于以后计算机的学习具有很重要的意义。
